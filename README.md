# Andito Rizky

Full-stack developer building web apps and games — from K-pop photocard trackers to RPG games in Godot.

---

## Projects

### 🎴 [HIBIKISHOP PC](https://github.com/randitorizkypratama/PhotocardKpop)
K-pop photocard price tracker for IVE, aespa, and Hearts2Hearts. Pulls live listings from Pocamarket, maps them to MusicBrainz discography data, and serves them through a clean timeline UI.
- AI-powered news with admin publish workflow
- Per-user collection tracking with account auth
- Photocard identify via CLIP embeddings
- Daily sync via GitHub Actions · **Nuxt 4 · Vue 3 · Turso · Vercel**

### 🃏 [DeckMaker](https://github.com/randitorizkypratama/DeckMaker)
Card deck builder with browsing, collection management, and an admin panel. Mobile-responsive down to 320px with Turso persistent storage.
- **Nuxt · Vue 3 · TypeScript · Turso**

### 🌳 [FamilyTree](https://github.com/randitorizkypratama/FamilyTree)
Aplikasi pohon keluarga dengan visualisasi silsilah, kalender, statistik, dan panel admin multi-cabang. Dukungan bahasa Indonesia, English, dan Sunda.
- Cookie sesi httpOnly, CSRF/rate-limit middleware, CSP nonce
- **Nuxt · Vue 3 · TypeScript · Turso**

### 🎮 [FACADE](https://github.com/randitorizkypratama/FACADE)
Story-driven RPG game built in Godot. Features a full combat system, NPC routines, quest/flag management, save validation, Echo/Reflection mechanics, and 2466 automated regression checks.
- `v0.9.3` — Fundamental Completion
- **GDScript · Godot 4**

### 🧑‍💻 [Portfolio](https://github.com/randitorizkypratama/Portofolio)
Interactive portfolio as an RPG browser game. Explore a village, talk to NPCs, craft items, adopt pets, hunt for treasure, and export a character card — while the CV sits right underneath.
- PWA installable · Photo mode · Skin shop · Loudness-safe audio
- **TypeScript · CSS · HTML**
